# Community Code of Conduct

FDEKit welcomes contributors of every experience level and background. Be respectful,
patient and specific. Critique ideas and code without attacking people.

Expected behavior includes giving constructive feedback, acknowledging mistakes,
respecting privacy, and helping new contributors learn. Harassment, discrimination,
threats, sexualized conduct, doxxing, impersonation and repeated disruptive behavior
are not acceptable in project spaces or when representing the project.

Maintainers may remove harmful content, warn participants, temporarily limit participation,
or ban participants depending on severity and repetition. They will consider context,
avoid conflicts of interest and explain decisions where doing so protects affected people.

Report concerns using a private contact method explicitly published on the repository
owner's GitHub profile. Do not post private details in public issues. If no private contact
is available, request one without identifying the affected person or disclosing details.
A maintainer involved in a report should not decide its outcome.

This policy applies to issues, pull requests, Discussions and other project community spaces.
